# العمارة والمراحل — عقد التنفيذ (وثيقة الوكلاء)

**For agentic workers:** اقرأ `٠٠-للمالك.md` الأول (المِسطرة والفرامل)، ثم هذا الملف (العقد)، ثم `EXECUTION-PROMPT.md` (أمر البدء). هذا الملف هو المرجع الوحيد للترتيب والطبقات. أي خطة أخرى — داخل المستودع أو في فولدر الشركة — **متقادمة**، وممنوع إعادة التخطيط.

**Goal:** إنهاء المتجر وشغّاله السربي على ١٢ مرحلة متسلسلة، كل مرحلة تُنتج دليلاً حيّاً واحداً على الرابط المنشور، وصفر حقيقة لها أكثر من صاحب.

**Architecture:** سبع طبقات، كل طبقة تُستهلك من اللي فوقها فقط، وصاحب واحد لكل حقيقة (هوية، مواعيد، أرقام، غرف، إنذارات، دستور). المخزن تُعرّفه migrations فقط، والوصول له من مصنع عميل واحد بـ service_role. الأسطح الجديدة تحت `app/admin/v2/**`؛ اللوحة القديمة `app/admin/**` مجمّدة حتى المرحلة ١١.

**Tech Stack (مقاس من `package.json` و `node_modules`، مش من الذاكرة):** next **16.2.2** · react **19.2.4** · @supabase/supabase-js **2.103.3** · @supabase/ssr **0.6.1** · vitest **2.1.9** · playwright **1.60.0** · prisma **6.19.3** · typescript **5.9.3** · node **24.18.0**. نشر: Vercel Hobby · origin `github.com/azenithliving/azenith-living-os` · المسار `git push origin HEAD:main`.

**Spec:** `D:\alaa2\الشركة الجديدة\القائمة الجامعة - مسار الوصول للشكل النهائي.md` (٥٤ بند = مِسطرة القدرة) + `docs/ledger/transfers.json` (٥٣٢ ذرة = مِسطرة النقل).

## Global Constraints (سارية على كل مرحلة، تُنسخ حرفياً في رأس كل مهمة)

- صفر تكلفة · لا بطاقة بنكية · لا اشتراك مدفوع.
- لا أداة وهمية · لا رقم مختلق: كل رقم يُطبع يجب أن يكون ناتج قياس في نفس التشغيل (لا `computed`, لا انطباع).
- لا سر يُطبع: الأسماء فقط، أبداً القيم. لا `console.log` لمفتاح. لا commit لملفات `.env*`.
- أرقام عربية (٠-٩) على كل أسطح المالك، وصفر معرّفات آلة على شاشاته.
- لا حذف بلا كلمة صريحة: اللوحة القديمة، أي جدول، أي صفوف، تنظيف مفاتيح البيئة، أي أمر `delete`/`drop`/`truncate` في القاعدة → **توقف واسأل**.
- لا نشر بغير دليل حيّ على الرابط المنشور عند عرض ٣٩٠ بكسل مع صورة تم فتحها وقراءتها فعلياً.
- البوابات الأربع قبل أي تسليم: `npm run test` (baseline **2486**) · `npm run typecheck` · `npm run build` · قياس حيّ.
- الأدوات القياسية تكتب صفوفها فقط، وتحذف ما كتبته بنفسها بطابعها، وتطبع الباقي قبل أي ادعاء.
- لا `git reset --hard` · لا `--no-verify` · لا `git stash` في عمل مشترك · لا تعديل `package.json` لأمر جديد دون تسجيله في السجل.
